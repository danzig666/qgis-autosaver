about=Fork of Enrico Ferreguti's autoSaver. Saves the current project at a fixed interval with a countdown on the message bar (skip / postpone), optionally to a separate *.bak.qgz backup file, and optionally after a period of user inactivity. Modified layers in edit mode can be committed as well. A toolbar label shows the time left until the next autosave.

changelog=2.5 Qt6 / QGIS 4 support; inactivity autosave, message-bar countdown with skip/postpone, toolbar countdown; fixed inactivity monitoring stopping after the first prompt, backup mode hiding unsaved changes, postpone interval becoming permanent, hidden layers being ignored, commit failures reported as success; settings dialog rebuilt with validated spin boxes
    2.4 QGIS3 migration issues fixed
